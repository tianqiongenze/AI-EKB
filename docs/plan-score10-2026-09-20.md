# EKB 冲刺 10 分提升方案（多视角审查 · 待确认稿）

> 日期：2026-09-20 ｜ 现状：综合 8.0/10（九轮演进 6.1→8.0）
> 审查视角：① 国内外互联网大厂工程标准 ② 资深架构师（10 亿用户/百万并发经验尺度）③ 高级美工/设计系统 ④ SRE/测试 ⑤ 安全合规
> **执行纪律：本方案经用户逐项确认后开工；每一项都有验收标准；不产生可验证证据的项不做。**

---

## 一、诚实的前置结论（必须先对齐）

**"10 分左右"的可达成定义**：代码与工程体系（可迁移部分）可以做到 **9.3~9.5**；**9.5 以上无法由代码产生**——按本评审体系定义，最后一段分数只能来自三类生产证据：① CRDB license（否则并发事务上限封顶数据面上限）② 连续 SLO 运行面板（30 天）③ 第三方测评/渗透（CNAS 依据 GB/T 25000.51、等保三级）。方案把这些列为"用户决策项"而非假装能写出来。

## 二、分维度差距与提升项

### A. 资深架构师视角（当前：架构 8.2 / 可扩展 6.5 / 可靠 7.5）

| # | 差距 | 提升项 | 验收 | 环境 |
|---|---|---|---|---|
| A-1 | DB 驱动层仍同步（P0-1 尾项） | 存储层 async 门面（`AsyncControlPlaneFacade`：`asyncio.to_thread` 包装 + 热路径 handler 改 `async def`），不动 SQLite/TiDB/CRDB 三驱动本体 | 压测对比报告：异步 handler 下 p99 不劣化、事件循环零阻塞（中间件计时） | ✅ 可做 |
| A-2 | 双 Store 方言重复（SQLite/TiDB 两份 SQL） | 方言合并：`SQLDialect` 参数化（占位符/自增/JSON 函数三差异点），TiDB store 委托 SQLite 语义 | 契约测试同套跑双驱动（testcontainers SQLite 真跑 + TiDB 语法单测） | ✅ 可做 |
| A-3 | Pulsar 发布后端未在集群启用（InMemory 降级中） | 接 `pulsar://pulsar-broker.infra.svc.cluster.local:6650`，`EKB_EVENT_PUBLISHER_BACKEND=pulsar`，验证真实 topic 发布 + readyz mismatch 检查激活 | flywheel 事件在 Pulsar topic 可消费到；relay 指标递增 | ✅ 可做（T7 已验证可达） |
| A-4 | schemas.py 494 行单文件（DDD 尾项） | 按限界上下文拆 `schemas/` 包（skills/governance/a2a/connectors/datalake/domain/retrieval），保留 `schemas.py` 再导出 | 91+ 测试全绿；契约门禁扫描路径更新 | ✅ 可做 |
| A-5 | Java 治理规则硬编码；Go 无 Prometheus 格式 | Java 策略外置配置化；Go `/metrics/gateway` 输出 Prometheus 文本 | 各自测试通过 | ✅ 可做 |

### B. 高级美工/设计系统视角（当前：前端 7.0——**功能齐但"工程感"重，离大厂产品级差一档**）

对标：[Muz.li 2026 Dashboard 50 佳](https://muz.li/blog/best-dashboard-design-examples-inspirations-for-2026)、[Perceptive 12 原则](https://www.perceptive-analytics.com/enterprise-dashboard-design-principles-bi-adoption)、[Mockplus 实践](https://www.mockplus.com/blog/post/dashboard-design-best-practices-examples)：层级分明、低视觉噪音、空态/加载态、专业图表。

| # | 差距（现状实测） | 提升项 | 验收 |
|---|---|---|---|
| B-1 | 全部数据裸 `<pre>` JSON 展示（审计/容量/Skill 结果）——**最大扣分点** | `DataTable` 组件（列定义/斑马纹/悬停/溢出省略/空态插画位）；审计页改真表格 | 截图评审 + 组件测试 |
| B-2 | 无加载/空态体系 | `Skeleton` 骨架屏 + 空态组件（图标+引导文案+CTA） | 所有异步卡片具备三态（loading/empty/data） |
| B-3 | 品牌感弱（无 logo/favicon/登录页） | SVG logo + favicon + 登录页（Token 输入，存 sessionStorage，401 统一跳转） | 浏览器 tab 图标；未登录访问跳登录 |
| B-4 | 容量估算结果无可视化 | 结果卡片化：QPS/算力卡 + 对比条形图（复用 SVG 方案） | 数值-图形双呈现 |
| B-5 | 无通知反馈 | `Toast` 轻通知（成功/失败），替代当前文字行 | 操作反馈 3s 自动消失 |
| B-6 | 可访问性未审计 | 焦点环/对比度全过 4.5:1/键盘导航 tab 顺序 | 手动 WCAG 2.2 AA 抽查清单 |
| B-7 | 布局未响应式 | 侧边导航（≥1024px）+ 顶栏折叠（窄屏） | 1280/1920/手机宽三档截图 |
| B-8 | 预算门禁 | gzip 保持 <200KB（组件自研不加图表库） | CI 硬门禁保持 |
