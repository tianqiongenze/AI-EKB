# 需求-实现差距审计报告（2026-09-20）

> 审计代理全量扫描源文档（工业 AI 知识库全栈架构 + 4R V5）与 src/services/web 全部代码后产出。
> 核心发现：**治理面/控制面/部署体系 8.6 分，但源文档的核心业务价值（知识检索/对话推理/文档处理/AI 引擎）在代码中多为骨架或缺失**——这就是"简陋感"的结构性根因。

## "简陋感"根因（Top 5）

1. **核心 AI 引擎整体缺席**：`mcp_gateway.py` 返回 `{status:executed}` 硬编码 stub，无 vLLM/流式/Agent。前端拿不到"AI 在思考"的实时数据流 → Skills 页只能放一个按钮
2. **数据面只接结构化记录未接知识内容**：connectors 拉的是 OData 记录不是文档/图纸/SOP，无 OCR/PDF/chunking pipeline → 知识库"无知识可展"
3. **检索三腿两腿空转**：graph 腿 None 钩子、lexical 腿 SQL LIKE 非 BM25、无 reranker → 搜索结果不值得做成富列表
4. **前端组件齐全但数据源单一**：9 组件产品级但只消费 readyz/metrics/audit/capacity 四个运维端点，"工具好、内容空"
5. **大屏对标错位**：源文档要求设备/产线/质量/能耗工业大屏，实现复用了运维监控视图
