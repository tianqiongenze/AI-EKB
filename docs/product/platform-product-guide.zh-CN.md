# 雅迪EKB平台产品功能说明书（中文）

## 1. 产品概述

雅迪EKB平台面向集团级工业场景，提供统一知识治理、智能体协作、图谱与向量检索、审计与合规能力。

## 2. 产品功能矩阵（细化）

1. 技能生命周期治理（注册、评审、预发、生产）
2. MCP 调用治理（认证、限流、策略、审计）
3. A2A 协议化协作（消息封装、路由、消费）
4. 图数据能力（关系写入）
5. 向量能力（写入与检索）
6. 事件总线（Pulsar）与 Outbox 一致性
7. 容量估算与上线门禁（Harness）

## 3. 实现原理（关键链路）

### 3.1 MCP 调用链路
请求 -> 鉴权 -> 限流 -> 策略校验 -> 执行 -> 审计落库 -> 事件发布。

### 3.2 A2A 协作链路
发布 envelope -> Outbox -> Pulsar topic -> Consumer -> Dispatcher -> Handler。

### 3.3 图向量检索链路
图写入通过 Neo4j 批量关系 upsert；向量通过 Milvus upsert/search，支持业务检索增强。

## 4. 部署与运维能力

1. K8s/Helm/Kustomize 多环境部署
2. 裸机一键部署脚本（Docker Compose）
3. Secret 注入与配置分层

## 5. 适用业务场景

- 研发知识问答
- 制造工艺优化
- 质量异常分析与追踪
- 售后智能辅助

## 6. 路线图（工业级）

1. 下一阶段：A2A Dispatcher业务化、Go网关真实Pulsar发布、Java图推理深度化
2. 中期：多区域多活、全链路观测、合规报表
3. 远期：10B用户/10M并发目标下的全局调度与自治

## 7. 发布前自动验收闭环

- CI 对 Python/Java/Go 运行时路径进行校验。
- Neo4j/Pulsar/Milvus 集成服务在流水线中联调。
- release-gate 强制检查契约与双语文档齐备。
