# Yadea EKB Platform Product Guide

## 1. 产品定位

Yadea EKB 是雅迪科技集团工业级 AI 知识库平台，用于连接研发、制造、质量、供应链、售后等业务场景，实现多区域、多工厂、多系统协同的知识治理和智能协作。

## 2. 核心能力

1. **治理控制面**：MCP + Skill + Harness 全流程治理与审计
2. **智能体协作**：A2A 协议封装、任务分发与追踪
3. **多模态检索**：向量检索 + 图谱推理
4. **多区域部署**：总部/区域/工厂三级架构
5. **安全与合规**：数据驻留、审计追溯、策略隔离

## 3. 模块说明

| 模块 | 说明 |
|---|---|
| Python 控制面 | MCP/Skill/Harness/Audit/Outbox
| Go 网关 | 低时延入口 + 缓存 + 鉴权
| Java KGraph | 图谱推理与企业知识增强

## 4. 运行原理（简化）

1. 用户请求进入 Go 网关
2. MCP 调用由控制面治理
3. A2A 消息分发执行任务
4. 结果通过审计/事件流追踪

## 7. 组件依赖

- TiDB（控制面持久化）
- Pulsar（事件/A2A 主干）
- Redis（缓存）
- Neo4j（图谱）
- Milvus（向量检索）

## 5. 典型应用场景

- 研发设计知识检索
- 制造工艺异常分析
- 质量缺陷溯源与风险预警
- 售后维修知识推荐

## 6. 工业级价值

- 全链路治理
- 高并发吞吐
- 多租户隔离
- 安全合规
