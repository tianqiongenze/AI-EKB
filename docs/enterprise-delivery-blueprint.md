# 企业级垂类AI知识库上线蓝图（可执行版）

## 1. 目标与范围

面向大型工业集团建设统一的垂类 AI 知识库平台，覆盖全国多分公司/工厂与全球多洲生产基地，满足以下硬指标：

- 并发访问能力：100万+ 在线用户规模
- 可用性目标：核心链路 99.99%
- 时延目标：交互问答首 Token P95 ≤ 2s（同地域）
- 安全目标：零信任、全链路可审计、数据分级与驻留合规

本蓝图在现有两份设计文档基础上做“工程化升级”：

1. 把中心-区域-边缘三级架构落到控制面/数据面分离
2. 把 MCP 从概念升级为生产级策略边界
3. 把 Agent Skills 引入版本化治理
4. 把 Harness 作为发布门禁

## 2. 目标架构（控制面 + 数据面）

### 2.1 控制面（Global Control Plane）

控制面全局统一，由总部双中心多活承载：

- IAM/SSO 与工作负载身份
- MCP Gateway 与 Policy Engine
- Skill Registry 与 Artifact 签名
- Model Registry 与路由策略
- Harness Orchestrator 与评测结果仓
- 全局审计与观测标准

### 2.2 数据面（Residency-Bound Data Plane）

数据面按驻留域分区部署，国内与海外域独立：

- Ingestion：文档/系统/事件连接器
- Retrieval：向量库 + 全文索引 + 图谱引擎
- Inference：区域推理集群 + 边缘轻量推理
- Cache：语义缓存、会话缓存、热点知识缓存
- Local Policy Enforcement：租户与工厂级数据访问控制

原则：默认不跨域复制原始内容，仅在策略允许时进行元数据联邦检索。

## 3. 关键能力设计

## 3.1 RAG 三索引融合

- 向量检索：语义召回
- 全文检索：制度条款、编号、关键词精确匹配
- 图谱检索：设备-工序-故障-备件-专家关系推理

融合策略：RRF + Reranker + 证据可追溯输出。

## 3.2 知识分级与隔离

- Global：集团公共知识（总部下发，区域与工厂只读）
- Regional：区域/事业部知识（辖区内共享）
- Local：工厂本地知识（默认不出厂）

每条知识对象要求携带统一元数据：

- tenant_id
- region_id
- plant_id
- confidentiality_level
- domain
- source_uri
- doc_version
- effective_at
- expires_at

## 3.3 推理路由与降级

- L0：语义缓存命中，直接返回
- L1：轻量模型 + Top3 上下文
- L2：主力模型 + 完整 RAG
- L3：仅证据返回 + 人工/工单引导

降级事件必须纳入审计与容量评估。

## 4. MCP、Agent Skills、Harness 三位一体治理

## 4.1 MCP 生产边界

所有工具调用必须经过 MCP Gateway：

- 鉴权与授权
- Tool allowlist
- 输入输出 schema 校验
- 秘钥代理与脱敏
- 限流与熔断
- 审计留痕

## 4.2 Agent Skills 治理

- 技能作为受管制工件
- 版本化发布与签名校验
- 风险等级分层审批
- 作用域约束（可访问数据域、可调用工具集）

## 4.3 Harness 发布门禁

任一变更在进入生产前必须通过：

- Quality Suite：相关性、忠实性、可解释引用
- Safety Suite：注入攻击、越权工具调用、敏感泄露
- Regression Suite：版本回归、时延和成本回归

## 5. 组织与实施模型

## 5.1 分层团队

- 平台控制面团队
- 数据面与检索团队
- 推理与模型工程团队
- 安全与合规团队
- 工厂侧落地团队
- SRE/平台运维团队

## 5.2 阶段路线图

### Phase A（0-6周）

- 建立控制面最小可用能力
- 打通文档接入到基础 RAG
- 建立基础观测与审计

### Phase B（6-14周）

- 扩展到多区域
- 接入 3-5 工厂边缘节点
- 上线 Skill Registry 与 Harness 门禁

### Phase C（14-24周）

- 规模化接入业务系统与实时事件
- 全面推行 MCP 策略治理
- 完成 HA/DR 演练闭环

## 6. 上线验收基线

- 架构合规：控制面/数据面边界清晰并可审计
- 安全合规：租户隔离、驻留域策略、零信任链路生效
- 性能压测：关键链路达到阶段 SLO
- 稳定性：故障注入与演练通过
- 可运维：仪表盘、告警、Runbook 完整
