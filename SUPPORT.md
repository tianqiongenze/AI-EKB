# Support

## Scope

This repository provides an enterprise-grade engineering baseline for a vertical AI knowledge base platform (control plane, governance, deployment assets, and multi-language service skeletons).

## Getting Help

1. Check `README.md` and `docs/` first
2. Search existing issues/discussions
3. Open a new issue with:
   - environment and version details
   - reproduction steps
   - expected vs actual behavior
   - logs/error output

## Support Boundaries

- ✅ Supported: repository code, deployment manifests/charts, documented APIs/contracts
- ⚠️ Best effort: custom integrations with proprietary systems (ERP/MES/SCADA)
- ❌ Not supported: private infrastructure incidents outside this repository

## Response Expectations

- Triage for new issues: typically within 3-5 business days
- Security issues: follow `SECURITY.md` private reporting flow
